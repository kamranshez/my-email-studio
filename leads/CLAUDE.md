# Leads folder rules

These rules apply to everything in this folder.

1. **These are made-up practice people.** Nobody in `leads.csv` is real.
2. **Never add real people or real email addresses.** Only invent new ones.
3. **Every row needs a consent value.** Do not leave the `consent` column empty.
4. **Never change the @example.com addresses.** That domain can never receive mail, so no real person is ever emailed.
